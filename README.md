# 💍 Luxury Wedding Invitation (Light Blue & Metallic Gold)

An interactive, responsive digital wedding invitation for **Gisser & Marialyn** featuring a 3D opening envelope, metallic foil gilded typography, synthesized celestial harp audio, countdown timer, and an RSVP modal.

## ✨ Features Included

1. **Envelope & Wax Seal Experience**:
   - Powder blue envelope with 3D folding flap.
   - Gilded metallic gold wax seal with initials and animated pulsing glow.
   - Realistic letter slide-out and elevation effect.
   - "Re-seal Envelope" button to fold the letter back and replay the experience.

2. **Luxury Theme**:
   - **Colors**: Powder/Sky Blue (`#e4eef6`, `#86a5bf`), Pearl Ivory (`#fdfdf9`), and Shimmering Metallic Gold (`#d4af37`, `#fdef9e`).
   - **Typography**: Google Fonts (*Cinzel*, *Cormorant Garamond*, *Great Vibes*, *Montserrat*).

3. **Audio & Effects**:
   - **Web Audio API Harp Arpeggio**: Plays a chime/harp strum upon breaking the seal (works without any external MP3 files).
   - **Ambient Floating Gold Dust**: Canvas-rendered shimmering particles floating in the background.
   - **Gold Foil Confetti Burst**: Cascades when the invitation reveals.
   - **Sound Mute / Unmute Button**: Positioned at top-right corner.

4. **Event Essentials**:
   - Live Days/Hours/Mins/Secs countdown timer.
   - Interactive RSVP modal with guest count, attendance selection, and confirmation message.
   - "Add to Calendar" button (direct Google Calendar integration).
   - "Location" button (Google Maps integration).

---

## 🚀 How to Run

Simply open `index.html` in any web browser (Chrome, Edge, Safari, Firefox):
* Double click `index.html` in your file explorer.
* Or right click `index.html` -> Open with -> Your preferred browser.

## ✏️ How to Customize
- **Names**: Edit the text inside `.couple-names` in [`index.html`](file:///c:/Users/User/Downloads/Wedding/index.html).
- **Date & Venue**: Edit the `.event-date-badge` and `.venue-info` sections in [`index.html`](file:///c:/Users/User/Downloads/Wedding/index.html).
- **Countdown Target**: In [`script.js`](file:///c:/Users/User/Downloads/Wedding/script.js), adjust `weddingDate = new Date('2027-09-18T16:00:00').getTime();` to your wedding date.
